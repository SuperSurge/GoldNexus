# 知识库原始文档（RAG 数据源）

本目录的 `.md` / `.txt` 文档是 RAG 语义检索的数据源，P2 阶段用 `ingest.py` 建库。

## 文档清单

1. `平台业务规则.md` —— 额度、利率、期限、风控、合规（核心规则）
2. `贷款产品说明.md` —— 多数据源融合产品列表
3. `还款规则.md` —— 等额本息/等额本金、提前还款、逾期罚息
4. `逾期政策.md` —— 逾期后果、征信影响、催收流程
5. `常见问题FAQ.md` —— 高频问答口径

## 建库

在项目根目录执行：

```bash
python -m app.rag.ingest
```

或调用接口 `POST /ingest`。首次会下载 embedding 模型（bge-large-zh-v1.5，约 1.3GB，走 hf-mirror 镜像）。

## 注意

- 利率、额度、期限等关键数据要明确写，供防幻觉测试引用。
- 与前置规则库（300+ 高频 FAQ 精确匹配）区分：规则库命中即返回，命不中的长尾问题才进本模块的 RAG。
